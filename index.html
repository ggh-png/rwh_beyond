RWH 프로젝트 안내¶

이 저장소에는 PiPER 로봇 팔의 모델 기반 집기와 Husky의 SLAM·Nav2 운용이 함께 있습니다. 지금 SAM 3·GraspGenX·MoveIt 실험을 이해하려면 아래 PiPER 안내부터 읽으세요.

PiPER 집기: 이 순서로 읽으세요¶

순서 문서 읽고 나면 알 수 있는 것
1 전체 흐름 한눈에 세 컨테이너와 네 저장소가 맡은 일, 한 번의 집기 순서
2 컨테이너는 어떻게 구축했나 이미지·모델·볼륨·GPU·네트워크·시작 스크립트의 관계
3 모델과 어떤 데이터를 주고받나 RGB → mask → XYZ → 파지 행렬 → 로봇 목표의 변환
4 처음 터미널부터 실행 Docker 접근, 모델 시작, runner, RViz, 관측·집기·종료
5 코드를 따라 읽기 BT XML에서 SAM·GraspGenX·MoveIt 호출까지 파일과 함수 추적

필요한 부분 바로 찾기¶

  • 두 모델을 구체적으로 어떻게 썼나? SAM 3 구현, GraspGenX 구현
  • 다른 물체를 지정하고 싶다: 대상 변경
  • 마스크·점군·파지 후보가 안 보인다: RViz 토픽과 설정
  • BT 노드를 수정하고 싶다: 노드별 포트와 endpoint, 헤더·CPP 구성
  • 추론만 호출하고 싶다: 독립 추론 API
  • 이전 실험에서 무엇을 검증했나: 검증 결과와 제한, 과거 SAM 실험 기록
  • Husky를 주행시키고 싶다: Husky 시작 안내

이 안내는 2026-11-11의 workspace 소스를 기준으로 합니다. 기본 집기 경로는 실제 SAM·GraspGenX를 사용하는 MuJoCo 시뮬레이션입니다. 실물 PiPER driver/MoveIt 실행 경로는 별도로 존재합니다.
