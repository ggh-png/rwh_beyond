# 2026-11-10 GraspGenX·ROS Bridge·BT 집기 통합

## 구현 내용

- 추론 전용 Dockerfile/Compose, 공식 소스 버전 고정, checkpoint/cache/TRT/log 영속화,
  health check 및 로컬 rootless Podman GPU 실행 스크립트를 추가했다.
- 로컬 RTX 3060에서 실제 piper_hand 모델 추론 → ZMQ → ROS Action 후보 수신을 확인했다.
  공식 2048점 샘플의 100개 생성/상위 20개 요청에서 후보 20개와 점수 수신,
  CLI 전체 약 1.27초, 관측 VRAM 약 1 GB였다. 단일 조건의 측정이며 일반 성능 보장은 아니다.
- rwh_beyond_msgs에 InferGrasps/RunGraspStep/GraspCandidate를 추가하고
  rwh_beyond_grasp_bridge에 입력 변환, 행렬 검증, timeout/cancel/동시 요청 처리를 구현했다.
- 빨간색 RGB 마스크 → Depth 역투영 → 객체 XYZ → 실제 모델 후보 → 촬영 시각 TF/TCP
  보정 → IK/충돌/경로 검사 → 접근/접촉 확인/리프트 흐름을 MuJoCo 전용으로 구현했다.
- GraspStep/MoveObservation BT 플러그인과 Groot2 모델을 추가했다.
  추론은 prepare에서만 수행한다. attach는 실제 접촉 확인 후 MoveIt scene에 등록하며
  MuJoCo에서 강제로 물체를 고정하지 않는다.
- ros_runner 의존성은 bt_demo → grasp_bridge → piper_sim이다.
  runner는 ROS 프로세스만 관리하며 GPU 모델은 별도로 기동한다.
- moma-mj-lab에 색상 기반 대상 점 제외, 물리 접촉/높이 검증 서비스,
  성공한 닫기 명령 유지와 RViz 표시를 추가했다.

## 운영 상태와 범위

모델 컨테이너는 tini/sleep infinity로 유지하고 start_server.sh를 exec로 따로 실행한다.
Ctrl+C로 모델만 종료할 수 있다. 상태는 health로 확인하며 실행 여부를 문서의 고정값으로
가정하지 않는다. [운영 명령과 전체 BT 설명](red-box-grasp.md)을 참고한다.

현재 저장된 demo.xml은 MoveObservation이 주석 처리되고 마지막 MoveHome이 추가된
사용자 구성을 보존했다. 관측 자세를 포함한 이전 트리에서 상자 약 7–8 cm 상승,
취소 복원·재실행·이미 든 상태의 goal 차단을 검증했다. 현재 트리의 관측 생략과
마지막 홈 복귀를 포함한 전체 집기는 이번 문서 정리에서 재실행하지 않았다.
장시간 파지 안정성 튜닝은 범위를 확대하지 않았다. 내려놓기/실물 동작은 미구현이다.

원격 RTX 5090 서버는 SSH 진단만 완료했으며 Docker/sudo 권한에서 차단된 상태다.
호스트 설정 변경이나 원격 모델 실행은 수행하지 않았다. 로컬 성공과 원격 미검증을 구분한다.
