## 운영 상태와 범위

모델 컨테이너는 tini/sleep infinity로 유지하고 start_server.sh를 exec로 따로 실행한다.
Ctrl+C로 모델만 종료할 수 있다. 상태는 health로 확인하며 실행 여부를 문서의 고정값으로
가정하지 않는다. [운영 명령과 전체 BT 설명](red-box-grasp.md)을 참고한다.

현재 저장된 demo.xml은 MoveObservation이 주석 처리되고 마지막 MoveHome이 추가된
사용자 구성을 보존했다. 관측 자세를 포함한 이전 트리에서 상자 약 7–8 cm 상승,
취소 복원·재실행·이미 든 상태의 goal 차단을 검증했다. 현재 트리의 관측 생략과
마지막 홈 복귀를 포함한 전체 집기는 이번 문서 정리에서 재실행하지 않았다.
장시간 파지 안정성 튜닝은 범위를 확대하지 않았다. 내려놓기/실물 동작은 미구현이다.

원격 RTX 5090 서버는 SSH 진단만 완료했으며 Docker/sudo 권한에서 차단된 상태다.
호스트 설정 변경이나 원격 모델 실행은 수행하지 않았다. 로컬 성공과 원격 미검증을 구분한다.

## SAM 3 가중치 승인 후 실제 실행

공식 모델 접근과 fine-grained 토큰의 public gated repo 읽기 권한을 확인한 후
sam3.pt를 다운로드했다. 토큰은 사용자 숨김 입력/개인 캐시에만 저장했다.
실제 SAM 모델 health와 GPU 인식을 확인했다.

- MuJoCo RGB-D 320×240에서 `red box`/`cube` 텍스트로 실제 mask 생성.
- RGBD Action → SAM mask → 실측 XYZ → GraspGenX 후보 20개 수신 약 1.06초.
- GPU 관측: SAM 약 5480 MiB, GraspGenX 약 1002 MiB. 정확한 peak는 아니다.
- TF 도착 race는 정확한 촬영 시각을 보존한 2초 timeout 대기로 수정했다.
- 독립 domain baseline BT: 실제 양쪽 접촉과 7 cm 이상 상승 성공.
- runner 자동 기동·준비 중 취소/영역 복원·재실행 리프트·보유 중 재goal 차단·종료 성공.
- 사용자 원본 BT XML은 유지했다. 검증용 baseline은 관측 자세를 켜고 마지막 홈 복귀를
  제외했다. 장시간 안정성, 실물, 복수 객체 성공률, 사용자 원본 트리 전체는 미검증이다.
- Bridge/runner 49 tests와 시뮬레이터 4 tests 재통과. 문서 빌드·diff 검사 통과.

[실제 모델·BT·runner 상세 기록](sam3-perception.md)과 JSON/마스크 이미지를 추가했다.
GPU 모델은 실행 상태로 유지하고 테스트 ROS 프로세스는 정리했다.


## SAM 마스크 → 로컬 점군 → GraspGenX를 BT 단계로 분리

사용자가 요청한 최종 데이터 경로를 BT에 명시했다. GraspStep의 segment_target은
RGB를 SAM으로 보내 마스크를 받고, build_object_cloud는 로봇 PC ROS CPU에서 같은
Depth/K를 역투영해 PointCloud2를 먼저 발행한다. prepare는 그 점군을 POINT_CLOUD
Action으로 보내 GraspGenX 추론·후보 검사를 한다. 별도의 RGBD 편의 Action도 유지한다.

- 관측 30초 만료 및 팔 관절 변화 시 재관측을 요구한다. 실패/취소 시 관측 context 정리.
- 기본 demo.xml에 위 두 단계를 추가하고 MoveObservation을 활성화했다. 마지막 홈 복귀 유지.
- baseline에서 로컬 점군 2780점 → 추론 시작 순서와 실제 파지/리프트 성공.
- 전체 기본 트리에서 2783점 → 약 7.6 cm 리프트 → 홈 복귀, 양쪽 접촉 유지 성공.
- 한 전체 트리 시도는 관측 이동 전 START_STATE_INVALID로 중단돼 실패 기록도 보존했다.
  해당 시도에서 SAM/점군 단계는 실행하지 않았으며 충돌 검사는 해제하지 않았다.
- Bridge/runner 단위·통신 검사 52 tests와 3 subtests 통과.
- mesh는 만들지 않았다. GraspGenX의 XYZ 입력을 사용하며 완전한 뒷면 형상 복원은 보장하지 않는다.

실측 수치와 실패를 포함한 기록은 [SAM 로컬 점군 실험](sam3-perception.md)에 정리했다.
원격 공용 GPU 서버 배포와 실물 로봇 동작은 이번 실험 범위가 아니다.


추가 runner에서는 취소/복원과 재실행 리프트 후 5초 유지 시 물체가 미끄러졌다.
다른 시작 시도는 lifecycle get_state 요청 실패로 중단됐다. 전체 트리 성공 실험과
분리해 기록했으며 장시간 파지 튜닝을 범위 밖으로 유지했다. 로컬 XYZ를 PLY/NPY로
저장하고 동일 점군으로 실제 서버 후보 반환도 확인했다.
