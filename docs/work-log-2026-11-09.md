## Commands

```bash
# Hardware: CAN driver + MoveIt
ros2 service call /ros_runner/activate_piper_moveit std_srvs/srv/Empty '{}'

# Simulation: MuJoCo + MoveIt + RViz
ros2 service call /ros_runner/activate_piper_moveit_sim std_srvs/srv/Empty '{}'
```

The two runners deactivate one another before starting.

## Gripper execution finding

The official PiPER driver publishes the physical gripper width and force through
`/feedback/joint_states`: `gripper.position` is width in meters and
`gripper.effort` is force in newtons. It also accepts gripper force in
`/control/joint_states`.

MoveIt's stock FollowJointTrajectory completion is position-based. A gripper
closing onto an object can therefore report `GOAL_TOLERANCE_VIOLATED` even when
the fingers apply a valid holding force. A behavior-tree gripper action should
evaluate the PiPER force feedback for grasp success instead of relying solely on
the MoveIt trajectory result.
